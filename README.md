# Forever Suite – Downloads

Addons für **World of Warcraft Forever** von Dr. Snoelk: Navigation mit gelerntem Wegenetz, Weltsuche, Quest-Tracker,
Sammeln, Angeln, Charakterstände, Wappen-Designer und Datenaustausch in Gilde und Gruppe. Alles aus einer gemeinsamen
Basis, ohne fremde Bibliotheken.

## ⬇️ Neueste Version

**[Zur neuesten Version](../../releases/latest)**: dort die ZIP-Datei unter „Assets“ herunterladen.

## Installation

1. **Spiel ganz beenden.**
2. Unter `World of Warcraft\_retail_\Interface\AddOns` (bzw. dem AddOns-Ordner deines Forever-Clients) die alten
   `Forever…`-Ordner löschen.
3. Die Ordner aus dem ZIP dort hineinkopieren und das Spiel starten.

Deine Daten bleiben bei einem Update erhalten, sie liegen getrennt in den SavedVariables.

## Was drin ist

| Addon | Wofür |
|---|---|
| ForeverCore | Gemeinsame Basis und Weltsuche (Pflicht) |
| ForeverExchange | Datenaustausch mit Gilde oder Gruppe (standardmäßig aus) |
| ForeverNavigation | Routen über das selbst gelernte Wegenetz, Reisen mit Schiffen, Flügen und Portalen |
| ForeverQuest | Aufgeräumter Quest-Tracker |
| ForeverGathering | Kräuter und Erze auf Karte und Minimap |
| ForeverFishing | Eine Taste zum Angeln |
| ForeverCharacter | Charakterstände für den Forever Companion |
| ForeverTabard | Gildenwappen-Designer |

## Fehler melden

Mit Screenshot und dem Protokoll: in den Einstellungen der Suite „Erweitertes Protokoll“ einschalten, danach `/reload`.
