# Forever Suite 2.1 – Downloads

Addons für **World of Warcraft Forever**: Weltsuche, Navigation mit lernendem Wegenetz, Quest-Tracker, Sammeln, Angeln, Charakterstände, Gildenwappen und Datenaustausch.

## ⬇️ Download & Einstieg

**[Forever Suite 2.1 herunterladen](https://github.com/drsnoelk-a11y/forever-suite-releases/releases/tag/v2.1)** – unter **Assets** die Datei `ForeverSuite2_v2.1.zip` wählen.

### 📖 Neu: Einsteigeranleitung

**[Forever Suite – Schnellstart (HTML)](docs/forever-suite-schnellstart.html)**

Die Anleitung erklärt mit kurzen Schritten **Rechtsklick-Kontextmenüs**, **Weltsuche** (z. B. `Alt+S` selbst belegen), **Navigation**, **Sammeln**, **Angeln**, **Quests** und **Datenaustausch**. Für ein PDF die HTML-Datei im Browser öffnen und **Drucken → Als PDF speichern** wählen.

> GitHub zeigt HTML-Dateien in der Dateiansicht als Quelltext an. Zum Lesen die Datei über **Download raw file** herunterladen und im Browser öffnen.

## Installation

1. **WoW vollständig beenden.**
2. Die heruntergeladene ZIP entpacken.
3. Die enthaltenen **Forever…-Addonordner** in `Interface/AddOns` der **Forever-Spielinstallation** kopieren – nicht versehentlich in Retail.
4. Beim Upgrade alte Forever-Addonordner ersetzen. Die **SavedVariables** mit persönlichen Einstellungen und Daten nicht unbedacht löschen.

## Was drin ist

| Modul | Wofür |
|---|---|
| ForeverCore | Gemeinsame Basis und Weltsuche |
| ForeverExchange | Datenaustausch |
| ForeverNavigation | Navigation und gelerntes Wegenetz |
| ForeverQuest | Quest-Tracker |
| ForeverGathering | Kräuter- und Erzvorkommen |
| ForeverFishing | Angelhilfen |
| ForeverCharacter | Charakterstände für den Companion |
| ForeverTabard | Gildenwappen-Designer |

**Datenaustausch:** Bei einer neuen Installation von **v2.1** ist der Austausch standardmäßig **aktiv** und zunächst auf die **Gruppe** eingestellt. Das kann auch fremde Gruppenmitglieder betreffen. Wer das nicht möchte, kann ihn in den Einstellungen oder mit `/forever sync off` ausschalten.
